When good test scores lie

A one class lab that helps students discover why a random train and test split can overstate performance when data are grouped by site, cohort, sensor, or source.

The Teaching Problem

Students often learn the mechanics of model fitting before they learn to ask what a test set represents. This lab creates a concrete failure case. A model looks strong when rows are split randomly, but performance drops when the test set contains a site the model has never seen.

Module Structure

1. Fit one model

Students fit a baseline regression model to synthetic grouped data inspired by sensor readings and sparse biological counts.

2. Compare splits

They evaluate the same model with a random split and a group held out split.

3. Defend a claim

They write which score is appropriate for predicting at a new site and explain why.

What Students Compare

Validation Design What It Tests Main Risk
Random row split Performance on held out rows from sites already represented in training. Can leak site level signal into the test set.
Group held out split Performance on a site not represented in training. Harder test, but better aligned with deployment to a new site.
